# 01 · Competition — know the game

What the ABCC is, how it is judged, and what it has asked teams to do in the past.
Everything else in the repository defers to this folder on matters of rule and fact.

**Read in this order**

1. [`facts_and_rules.md`](facts_and_rules.md) — **the single source of truth.** Validated rules, round
   formats, the official rubric, past-case URLs, open questions for the organizers. Any rule dispute ends
   here, and this is the first file to update when 2027 information is published.
2. [`handbook.md`](handbook.md) — the narrative version, 13 sections. The one file every team member reads
   in full in W1. §12 is the **TBA tracker** for 2027.
3. [`judging_scoresheet.md`](judging_scoresheet.md) — printable rubric replica. The coach prints one per
   judge before every simulation.
4. [`past_cases.md`](past_cases.md) — all five editions, ten client profiles, a **re-crack brief** for each,
   and the patterns to expect in 2027. This is where simulation material comes from.

**[`past-case-pdfs/`](past-case-pdfs/)** holds six of the eleven official cases (2023 ×2, 2024 ×1, 2025 ×3).
The other five are URL-only — see the table in `facts_and_rules.md` and download them before the sessions
that need them (W14, W25).
