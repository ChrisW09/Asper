# Standing rules — all days

## Anonymity, dress, devices

- **Business professional** in every competition context — boots for
  outside, shoes carried
- Never name HSBI in front of judges — **team letter and fictional
  consulting name only**
- **Phones and smartwatches surrendered** before every prep window

## Clock, coach, evenings

- **The strategist owns the clock** — **the coach owns nothing** after a
  timed case releases
- **One 15-minute debrief per round**, then the topic is closed
- Hydrate; eat before, not during, the 3- and 4-h windows — the
  **10-hour day schedules its meals**

Every evening: chargers plugged · **template file opened and tested** ·
next day's **call time confirmed** in the team chat.

# The six days

## Day 0 · Arrival (Mon Feb 15)

| Time | What |
| --- | --- |
| afternoon | Prep kit check; test laptops, clicker, adapters |
| ~17:00 | **Registration + division draw** (2025 pattern) |
| evening | Free — light meal |

Note the letter and **all slot times** for the week; photograph the posted
schedule; confirm fictional-name usage. One 25-min prepared run-through,
then **STOP** — the deck went in on **Sat Feb 13**. Bed by 22:30.

## Day 1 · Opening + prepared case (Tue Feb 16)

| Time | What |
| --- | --- |
| 07:00 | Breakfast — no deck edits, the file is frozen |
| morning | **Opening ceremonies** — anonymity from the first handshake |
| by slot | Presentations in waves, **25 + 15** each |
| after | **Judge feedback session (15 min)** |
| evening | Social program if scheduled; bed by 22:30 |

Pre-room ritual — 60 s, three keys, one breath. All four speak;
**yellow at 5, red at 1** — in both segments.

## Day 1 · Afternoon protocol

- **Feedback session — attend without fail.** One note-taker; capture the
  rubric language judges use — it calibrates the heavier rounds
- After presenting: decompress, **no post-mortem yet**
- Social program: go; **be excellent company** — judges and organizers
  remember teams they liked
- Evening: **15-min team debrief max**; prep-room kit staged for tomorrow

## Day 2 · Boardroom case (Wed Feb 17)

| Time | What |
| --- | --- |
| 07:00 | Breakfast — carbs + protein; long day of thinking |
| 08:30–10:15 | Depart by slot; **phones surrendered** |
| 09:30–14:50 | **Staggered 4-h prep** (slot-dependent) |
| 14:00–17:00 | **3-min pitch + 22-min discussion** |
| ~16:30–17:00 | Feedback — capture, don't argue |
| evening | Social program if scheduled; 15-min debrief |

Pitch: one slide, red at 1. Discussion: appendices live, yellow 5 / red 1.
Seated, upright, hands visible; every member speaks; quarterback routes
questions. Tomorrow is the excursion — recover.

## Day 3 · Excursion day (Thu Feb 18)

- **Go** — and treat it as competition time: judges, volunteers and
  sponsors may be there; **anonymity still binds**
- No case work beyond **one 30-min team check-in**
- Evening — **reset for the 10-hour day:** kit staged, template and
  research bookmarks tested, food and water packed, the **10-h clock**
  re-read once; bed by 22:00

# Hand-ins & file discipline

## Deadlines & files

- **Prepared deck:** submitted **Sat Feb 13**, before travel — the
  deadline is expected on Feb 15; the file is frozen, no edits after
- Timed rounds end with **P6: save + USB** — never skipped
- Boardroom deliverables: deck, **one summary slide**, **one-page brief**,
  appendix bank — **brief and slide wording must match**
- The .pptx is **saved twice** (USB + laptop); every file lives on the
  **shared drive and a USB stick from minute one**

# Contingencies

## When things break

| Failure | The plan |
| --- | --- |
| Late transfer / lost | Leave **30 min earlier** — the plan, not the exception |
| Laptop dies in prep | Continue on three; shared drive + USB from minute one |
| Team member ill | Cross-cover per `role_playbooks.md`; all four still speak |
| Deck won't open | Saved twice; calmly ask volunteers |

The organizers accept no responsibility — **redundancy is ours**.
