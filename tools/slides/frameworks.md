# The principle

## A toolbox, not a menu

Judges punish framework name-dropping. They reward a structure tailored to
*this* case.

**The entry test for any framework:**

> If you cannot say in one sentence *what decision this framework helps the
> client make*, it does not go on a slide.

**The exit test, before freeze:**

> Remove it — is the argument weaker? If not, it was decoration.

## Three or four analyses, well executed

Beat eight sketched ones. Every time.

Two rules hold for every case type:

- **Every recommendation ends in a resourced implementation plan.**
  Implementation & Resources is the 2.5× category — more than any other.
- **Every number carries its assumption out loud.**

# The five-minute selector

## Types A–C

| Type | Always do these | Skip unless asked |
| --- | --- | --- |
| **A · Turnaround** | Cost/revenue decomposition · contribution margin by activity · cash runway · option screen against capacity | Five Forces · BCG |
| **B · Growth / entry** | Sizing top-down *and* bottom-up · entry-mode comparison · unit economics and break-even · gated-pilot logic | SWOT · value chain |
| **C · Premiumization** | Price ladder · margin-mix bridge · premiumization levers · channel economics by channel | Five Forces · Ansoff |

## Types D–F

| Type | Always do these | Skip unless asked |
| --- | --- | --- |
| **D · Opportunity screen** | Constraint-compliance table (centrepiece) · capability transfer · desirability–viability–feasibility · staged gates with spend | BCG · 7P |
| **E · Digital engagement** | Segmentation of the target group · funnel-leak analysis · CAC / CLV / payback · jobs-to-be-done | Five Forces · value chain |
| **F · Talent & change** | Priced gap · audience segmentation · €-per-outcome portfolio · a measurable proof mechanism | Porter · BCG · Ansoff |

## The decision each type faces

- **A** — Which one signature move closes the gap within real capacity?
- **B** — Where to play, how to enter, what to pilot first?
- **C** — Full reposition, or two-tier architecture?
- **D** — Which one adjacent opportunity passes every stated screen?
- **E** — Which segment-led bundle wins the group back at a CAC the CLV supports?
- **F** — Which segmented people-programme moves the groups that matter?

# The tools

## 1 · Problem framing

- **Issue tree / MECE** — break the core question into mutually exclusive,
  collectively exhaustive branches. Always start here.
- **Hypothesis-driven** — state a testable answer early, then budget time to
  *kill* it. A hypothesis nobody tried to break is a guess.
- **Pyramid principle (Minto)** — recommendation first, then 2–4 supporting
  arguments, then data. Governs the storyline *and* the Q&A.
- **The ask behind the ask** — write the client's decision as a sentence with a
  verb and a number before you analyse anything.

## 2 · Strategy & market

- **3C** — Company, Customers, Competitors. Fast situation scan.
- **Porter's Five Forces** — only the 2–3 forces that matter, and only when the
  *industry* is genuinely in question.
- **Value chain** — where value is created or lost; good for operations cases.
- **Ansoff** — useful to *frame* an option set, never as the analysis itself.
- **BCG** — needs a real portfolio and real share data to earn its slide.
- **SWOT** — only as a late synthesis, on one slide. Never as the analysis.

## 3 · Marketing & brand

- **4P / 7P** — product, price, place, promotion (+ people, process, physical
  evidence for services).
- **STP** — segmentation → targeting → positioning.
- **Customer journey / jobs-to-be-done** — for service-innovation cases.
  Find the leak, then fix the leak.
- **Brand ladder / premiumization levers** — quality, scarcity, story, price
  architecture, distribution, experience. Name the levers you pull **and the
  ones you refuse** — the refusal is what makes a positioning credible.

## 4 · Finance

*Finance lead owns the model; everyone defends any number in it.*

- **Unit economics** — contribution margin per unit or customer. The most useful
  quick model there is.
- **Break-even** — fixed costs ÷ contribution margin. Then ask the judge's
  question for them: is that volume plausible?
- **Market sizing** — top-down and bottom-up; quote a range when they disagree.
- **NPV / payback** — with assumptions stated.
- **Sensitivity** — best/base/worst on the one or two assumptions that move the
  answer; name the break point.
- **Financial ask** — cost, expected return, timeline. Always.

## 5 · Innovation & tech

*Innovation and CS leads own this block.*

- **Ideation** — brainwriting 6-3-5, SCAMPER, cross-industry analogies.
  Generate 10+, present 2–3.
- **Feasibility filter** — desirability, viability, feasibility. Kill on the
  weakest leg, **out loud, in the deck**: judges reward a visible kill.
- **Digital levers** — automation, personalization, platform, data
  monetization, AI-assisted service, channel shift.
- **MVP & pilot logic** — staged rollout, measurable pilot, named gate
  criterion. Judges distrust big-bang launches.

## 6 · Implementation — the 2.5× category

Never skip this. It is worth more than any other single criterion.

- **Roadmap** — 90 days / year 1 / year 2–3, with an owner and a milestone on
  every line
- **Resources** — headcount, budget, capability per phase:
  *who does this on Monday, paid from where*
- **Risks & mitigations** — 3–4 real risks, one line of mitigation each.
  No generic "market risk"
- **KPIs** — how the client knows it worked, with a baseline and a target date

# Storyline and Q&A

## The standard skeleton

1. Situation & core question
2. **Recommendation up front** — the money slide
3. Why: arguments 1 / 2 / 3 with evidence
4. Financials: cost, return, sensitivity
5. Implementation roadmap with owners and resources
6. Risks & mitigations
7. The ask / vision close
8. Appendix bank for Q&A

## Q&A protocol in brief

- **Answer first**, then explain. 20–30 seconds standard; 45 only for a
  financial walk-through with the appendix on screen.
- **Bridge, don't block** — "We focused on X; directionally, Y would mean…"
- **The quarterback routes** each question. One voice per answer.
- **Never contradict a teammate in front of judges** — add, don't correct.

Full protocol and 60 practice questions: `04-training/qa_drills.md`.

# Handle with care

## Five tools judges are tired of

| Tool | Why they get impatient | Use only when |
| --- | --- | --- |
| SWOT | Symmetrical, unprioritized, decision-free | One late synthesis slide, each quadrant tied to an action |
| Five Forces | Answers a question the case did not ask | Industry attractiveness is genuinely the decision |
| BCG | Needs share and growth data cases rarely give | A real multi-product portfolio is on the table |
| PESTEL | Reads as a list of things you googled | Regulation or macro shift is the actual driver |
| Ansoff | Frames options, proves nothing | Structuring an option set you then screen with numbers |

## The test, on every slide

**Remove the framework — is the argument weaker?**

If not, it was decoration. Cut it and give the space to the roadmap.
