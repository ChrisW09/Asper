# tools — building the PDFs and the session decks

Every markdown document in this repository is also published in the format it is
actually used in, **built beside its source**: `01-competition/handbook.md` →
`01-competition/handbook.pdf`, the same pairing
[`../08-briefing-slides/`](../08-briefing-slides/) already uses for its LaTeX deck.

**The markdown is the source of truth.** The PDFs and the four decks are build
output — never edit them by hand; edit the markdown and rebuild.

## What is a PDF and what is a deck

| Format | Which documents | Why |
| --- | --- | --- |
| **PDF** | 37 of the 41 documents — rules, plans, cases, drills, workbooks, logistics, the scoresheet, the folder indexes | They are read at a desk, marked up, or printed. Cross-links survive: an `.md` link in the source becomes a link to the corresponding PDF |
| **PPTX** | 4 documents that a coach *presents* to the team | A workshop is delivered from slides, not from a page. These are condensed rewrites, not the document with its paragraphs shortened |

The four decks, and the sessions they belong to:

| Deck | Slides | Session |
| --- | --- | --- |
| [`../03-team/coach_and_ai_rules.pptx`](../03-team/coach_and_ai_rules.pptx) | 15 | W1 kick-off — the coach briefs the team on the AI and coach rules |
| [`../04-training/frameworks.pptx`](../04-training/frameworks.pptx) | 21 | Framework workshop — the five-minute selector and the toolbox |
| [`../04-training/presentation_and_storyline_guide.pptx`](../04-training/presentation_and_storyline_guide.pptx) | 36 | Delivery workshop — action titles, the 3-hour build, the boardroom pitch |
| [`../06-templates/case_type_playbook.pptx`](../06-templates/case_type_playbook.pptx) | 34 | Case-type workshop — recognising the six types in ten minutes |

Their slide sources are the four markdown files in [`slides/`](slides/) — condensed
by hand, so they do **not** track their documents automatically. When one of those
four documents changes, re-read the slide source against it.

## Rebuilding

Needs `pandoc` and a LaTeX installation with `lualatex` (MacTeX or TeX Live).

```bash
python3 tools/build_handouts.py            # all 37 PDFs
python3 tools/build_handouts.py 01-competition/handbook.md   # or just one
python3 tools/build_decks.py               # the four decks
python3 tools/check_decks.py               # flag slides whose content overflows
```

## The files here

| File | What it does |
| --- | --- |
| `build_handouts.py` | Markdown → PDF: `# H1` becomes the title, `.md` cross-links are re-pointed at the built PDF or deck, pipe-table columns are re-weighted to their real content, a table of contents is added where a document lacks its own, and any glyph gap or overrunning line is reported |
| `pdf-preamble.tex` | The house style: XCharter body, Source Sans headings, deep-blue accents, running head, print footer |
| `build_decks.py` | The four slide sources → `.pptx` in the house style |
| `check_decks.py` | Estimates rendered text height per slide and flags anything that will not fit — no PowerPoint needed |
| `slides/make_reference.py` | Patches pandoc's default reference `.pptx` into the house style; rerun only when the style itself changes, then rebuild the decks |
| `slides/abcc-reference.pptx` | Generated by the above — the deck template pandoc styles from |

**Rebuild as the last step** after any change to a markdown document — above all
when the 2027 Competition Guide lands and the propagation order in
[`../DOCUMENTATION.md`](../DOCUMENTATION.md) §5 runs.
