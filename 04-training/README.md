# 04 · Training — the skills

Everything that turns four capable students into a team that can present a resourced recommendation in
English, under time pressure, to practitioner judges.

## The core skills trio

Three guides, read in this order, one per weekend block in Phase 2:

1. [`presentation_and_storyline_guide.md`](presentation_and_storyline_guide.md) — action titles, the
   storyline skeleton, the 3-hour production workflow, the 3-minute boardroom pitch, seated discussion
   technique, delivery for non-native speakers.
2. [`qa_drills.md`](qa_drills.md) — answer-first protocol, bridging, the quarterback system, and **60 hard
   questions** in five banks with model answer patterns.
3. [`business_math_drills.md`](business_math_drills.md) — anchor numbers, mental-math toolkit, **40 worked
   drills**, and the weekly 30-minute routine.

Each of the trio is delivered as a workshop from its own deck —
[`presentation_and_storyline_guide.pptx`](presentation_and_storyline_guide.pptx) (36 slides),
[`qa_drills.pptx`](qa_drills.pptx) (31), [`business_math_drills.pptx`](business_math_drills.pptx) (22) —
while the handout keeps the full drill and question banks. The decks are built from `tools/slides/`.

## Reference and language

- [`frameworks.md`](frameworks.md) — the framework toolbox, with a selector for *which* analysis a given
  case type actually needs. Not a menu to recite; judges punish name-dropping.
- [`english_phrasebook.md`](english_phrasebook.md) — DE–EN terminology, phrase banks for presentation, Q&A
  and boardroom register, numbers out loud, pronunciation traps. The English workshop is presented from
  [`english_phrasebook.pptx`](english_phrasebook.pptx) (31 slides).
- [`vocab_flashcards.csv`](vocab_flashcards.csv) — 87 cards. Anki: File → Import, comma-separated, first
  row is a header.

## The exercise programme

[`exercises/`](exercises/) holds the drills themselves — a 25-question format quiz, four solved workbooks,
and the week-by-week catalog that schedules all ≈200 items onto the calendar. Start at
[`exercises/README.md`](exercises/README.md).

**Weekly rhythm:** one skill session midweek (from the trio above) + one workbook exercise + one mini-case
from [`../05-practice-cases/`](../05-practice-cases/) + 30 minutes of individual drills on a third day.
If a week collapses: simulation > mini-case > workbook item > individual drills.
