# Framework Toolkit for Case Cracking

Not a menu to recite — a toolbox. Judges punish framework name-dropping; they reward a structure tailored to
the case. Use these as starting points and always adapt. If you cannot say in one sentence *what decision
this framework helps the client make*, do not put it on a slide.

**Where this sits:** `06-templates/case_type_playbook.md` tells you what a given *type* of case demands;
this file is the inventory of tools you draw from. The selector below is the bridge between them.

## The five-minute selector: what does this case actually need?

Classify the case first (playbook, first ten minutes), then take only the tools in your row. Three or four
well-executed analyses beat eight sketched ones, every time.

| Case type | The decision the client faces | Always do these | Usually worth it | Skip unless asked |
| --- | --- | --- | --- | --- |
| **A · Turnaround / revenue sustainability** | Which one signature move closes the gap within real capacity? | Cost-and-revenue decomposition (where the money leaks) · contribution margin by activity · cash runway · option screen against capacity | Peer benchmarking · stakeholder map | Five Forces · BCG |
| **B · Growth / market entry** | Where to play, how to enter, what to pilot first? | Market sizing top-down **and** bottom-up · entry-mode comparison · unit economics and break-even volume · gated-pilot logic | Ansoff to frame options · 3C on the target market | SWOT · value chain |
| **C · Brand repositioning / premiumization** | Full reposition or two-tier architecture? | Price-ladder / pricing architecture · margin-mix bridge · premiumization levers · channel economics by channel | STP · brand tracking read · competitor positioning map | Five Forces · Ansoff |
| **D · New product / opportunity screen** | Which one adjacent opportunity passes every stated screen? | Constraint-compliance table (the centrepiece) · capability transfer / right-to-win · desirability–viability–feasibility filter · staged validation gates with spend | Market sizing per candidate · NPV per gate | BCG · 7P |
| **E · Digital customer engagement** | Which segment-led bundle wins the group back at a CAC the CLV supports? | Segmentation of the target group · funnel-leak analysis · CAC / CLV / payback · jobs-to-be-done or customer journey | Digital-lever checklist · 4P on the offer | Five Forces · value chain |
| **F · Talent, trust & change** | Which segmented people-programme moves the groups that matter? | Priced gap (what the problem costs per year) · audience segmentation · €-per-outcome portfolio · a measurable proof mechanism | Stakeholder / governance path · benchmark of programme costs | Porter · BCG · Ansoff |

Two rules that hold for every type: **every recommendation ends in a resourced implementation plan**
(Implementation & Resources is the 2.5× category), and **every number carries its assumption out loud**.

## 1. Problem framing

- **Issue tree / MECE:** break the core question into mutually exclusive, collectively exhaustive branches.
  Always start here.
- **Hypothesis-driven approach:** state a testable answer early ("We believe X because A, B, C"), then use
  analysis to confirm or kill it. Budget time to *kill* it — a hypothesis nobody tried to break is a guess.
- **Pyramid principle (Minto):** recommendation first, then 2–4 supporting arguments, then data. Governs
  both the storyline and the Q&A ("answer first").
- **The ask behind the ask:** write the client's decision as a sentence with a verb and a number before you
  analyse anything. If the case gives constraints (a budget ceiling, a mission, a deadline), they are the
  screen every option must pass — see the constraint-compliance table under Type D.

## 2. Strategy & market

- **3C:** Company – Customers – Competitors (fast situation scan).
- **Porter's Five Forces:** industry attractiveness; use selectively — only the 2–3 forces that matter for
  this case, and only when the *industry* is genuinely in question.
- **Value chain:** where value is created or lost; good for operations cases (cf. Jazz Winnipeg's
  "operational idea", 2026).
- **Ansoff matrix:** growth options (market penetration / development, product development,
  diversification) — useful to *frame* an option set, never as the analysis itself.
- **BCG matrix:** portfolio decisions; needs a real portfolio and real share data to be worth the slide.
- **SWOT:** only as a *synthesis*, late, on one slide — never as the analysis.

## 3. Marketing & brand

- **4P / 7P:** product, price, place, promotion (+ people, process, physical evidence for services).
- **STP:** segmentation → targeting → positioning (cf. Coal & Canary premium→luxury, 2026).
- **Customer journey / jobs-to-be-done:** for service-innovation cases (cf. Access Credit Union and young
  customers, 2026). Find the leak, then fix the leak.
- **Brand ladder / premiumization levers:** product quality, scarcity, story, price architecture,
  distribution exclusivity, experience. Name which levers you pull *and which you refuse* — the refusal is
  what makes a positioning credible.

## 4. Finance

*Finance lead owns the model; everyone must be able to defend any number in it.*

- **Unit economics:** contribution margin per unit or per customer; the single most useful quick model.
- **Break-even:** fixed costs ÷ contribution margin. Then ask the judge's question for them: is that volume
  plausible given the funnel we just showed?
- **Market sizing:** top-down (population → filters) and bottom-up (capacity × utilization × price);
  sanity-check one against the other and quote a range when they disagree.
- **NPV / payback:** quick investment appraisal; state assumptions explicitly.
- **Sensitivity:** best / base / worst on the one or two assumptions that actually move the answer, and name
  the break point ("this stops working below 4,000 members").
- **Financial ask:** every recommendation ends with cost, expected return, and timeline.

Every calculation runs through `06-templates/case_financial_toolkit.xlsx`; the mental arithmetic behind
them is drilled in `04-training/business_math_drills.md`.

## 5. Innovation & tech

*Innovation and CS leads own this block.*

- **Ideation:** brainwriting 6-3-5, SCAMPER, analogies from other industries; generate 10+, present 2–3.
- **Feasibility filter:** desirability (customer wants it) – viability (makes money) – feasibility (we can
  build it). Kill on the weakest leg, out loud, in the deck — judges reward a visible kill.
- **Digital levers checklist:** automation, personalization, platform/marketplace, data monetization,
  AI-assisted service, channel shift.
- **MVP & pilot logic:** recommend a staged rollout with a measurable pilot and a named gate criterion;
  judges love de-risked implementation and distrust big-bang launches.

## 6. Implementation

*Never skip this: it is the 2.5× category, worth more than any other single criterion.*

- **Roadmap:** 90 days / year 1 / year 2–3, with an owner and a milestone on every line.
- **Resources:** headcount, budget, and capability per phase — "who does this on Monday, paid from where".
- **Risks & mitigations table:** 3–4 real risks, one line of mitigation each, no generic "market risk".
- **KPIs:** how the client will know it worked, with a baseline and a target date.

## 7. The standard storyline skeleton

1. Situation & core question (1 slide)
2. Recommendation up front (1 slide — the money slide)
3. Why: argument 1 / 2 / 3 with evidence
4. Financials: cost, return, sensitivity
5. Implementation roadmap with owners and resources
6. Risks & mitigations
7. The ask / vision close
8. Appendix bank for Q&A

Type-tuned variants of this skeleton — and the slide files that implement them — are in
`06-templates/case_type_playbook.md` and `06-templates/case-type-templates/`.

## 8. Q&A protocol

The full protocol, the drill formats, and 60 practice questions live in `04-training/qa_drills.md` —
that file is the standard. In brief:

- **Answer first**, then explain. Standard length 20–30 seconds; 45 seconds only for a financial
  walk-through with the appendix slide on screen.
- **Bridge, don't block:** "We focused on X; directionally, Y would mean…"
- **The quarterback routes** each question to the best-placed teammate; one voice per answer.
- **Never contradict a teammate in front of judges** — add, don't correct.

## Frameworks to handle with care

| Tool | Why judges get impatient | Use it only when |
| --- | --- | --- |
| SWOT | Symmetrical, unprioritized, decision-free | One late synthesis slide, with each quadrant tied to an action |
| Porter's Five Forces | Usually answers a question the case did not ask | The industry's attractiveness is genuinely the decision |
| BCG matrix | Needs share and growth data cases rarely provide | A real multi-product portfolio is on the table |
| PESTEL | Reads as a list of things you googled | Regulation or macro shift is the case's actual driver |
| Ansoff | Frames options, proves nothing | Structuring an option set you then screen with numbers |

The test for any framework, on any slide: **remove it — is the argument weaker?** If not, it was decoration.
