# 06 · Templates — what we build with

Competition-legal assets, built outside prep time. **Own** prebuilt templates are explicitly permitted;
**third-party** templates are not allowed for the prepared case.

## When a case lands, in this order

1. **Classify the case** — [`case_type_playbook.md`](case_type_playbook.md), first ten minutes. Six types
   (A turnaround · B growth/entry · C premiumization · D product screen · E digital engagement ·
   F talent/change), each with its core question, decisive analyses, storyline, judge attacks and counters,
   traps, and self-checks.
2. **Duplicate the matching skeleton** from
   [`case-type-templates/`](case-type-templates/) — `casetype_A…F`, 11–13 slides each, type-tuned storyline
   with coaching in the speaker notes. **Delete the red coach-briefing slide before any round.**
   For an unclassifiable case, fall back to [`team_template.pptx`](team_template.pptx), the general
   14-slide skeleton (incl. the boardroom one-slide summary).
3. **Run every number** through [`case_financial_toolkit.xlsx`](case_financial_toolkit.xlsx) — market sizing
   (top-down and bottom-up with cross-check), unit economics and break-even with a sensitivity grid, NPV and
   payback, CLV cohort. **Blue = inputs, yellow = key assumptions.** Never retype a figure you have not
   sanity-checked here.
4. **Boardroom rounds only:** fill [`judge_brief_template.docx`](judge_brief_template.docx) — one page,
   black and white, recommendation / three pillars / numbers table / risks / 90-day ask. Its wording must
   mirror the summary slide, because the judges read it before the team walks in.

## Anonymity

Every asset here is deliberately clean of HSBI branding. The templates carry the placeholder consulting name
**"Aurora Advisory"** — replace it with the fictional name the team registers with the organizers. The
division letter (A–I) is drawn at on-site registration, not chosen. **Never commit the HSBI name into any
file in this folder.**
