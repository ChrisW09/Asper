# 07 · Logistics — operating on the ground

The organizer exchange, and the script for the five days in Winnipeg.

**The files, in the order they become urgent**

1. [`registration_email_draft.md`](registration_email_draft.md) — **W1, send this first.** Ready to go to
   `aspercasecomps@umanitoba.ca`; it registers the team and puts the open questions (eligibility and fee,
   2027 agenda and prepared-case dates, roster requirements, rule deltas) into one exchange.
2. [`competition_day_runbook.md`](competition_day_runbook.md) — hour-by-hour sheets for all five days, the
   standing rules that apply all week, and the contingency plans. This is the file the team operates from in
   Winnipeg; print it. The pre-departure briefing in the week before the flight is presented from
   [`competition_day_runbook.pptx`](competition_day_runbook.pptx) (29 slides, built from `tools/slides/`).

Travel, visas, accommodation and everything else off the competition floor are handled outside this
repository — nothing here depends on them.

**The dates, and the one caveat.** The competition is **February 18–22, 2027**, which falls
**Thursday–Monday**. Both previous editions ran **Wednesday–Sunday** (2025: Wed Feb 19 – Sun Feb 23; 2026:
Wed Feb 18 – Sun Feb 22), so 2027 would be the first Thursday start. The day-sheets assume the published
Thu–Mon window with the round order inherited from 2025, and say so in place — **the round-to-day mapping is
the first thing to reconcile when the 2027 agenda lands.**
