# 09 · Handouts — the printable and presentable versions

Every markdown document in this repository, rendered into the format it is
actually used in: **37 PDFs to read, print and hand out**, and **four PowerPoint
decks** for the documents that exist to be presented in a session. The folder
mirrors the repository structure, so the path of a handout is the path of its
source with a different extension.

**The markdown files remain the source of truth.** Nothing in here is edited by
hand — everything is regenerated from `../` by the two scripts in
[`../tools/`](../tools/). Edit the markdown, rebuild, and the handout follows.

## What is a PDF and what is a deck

| Format | Which documents | Why |
| --- | --- | --- |
| **PDF** | 37 of the 41 documents — rules, plans, cases, drills, workbooks, logistics, the scoresheet, the folder indexes | They are read at a desk, marked up, or printed. Cross-links between them still work: an `.md` link in the source becomes a link to the corresponding handout |
| **PPTX** | 4 documents that a coach *presents* to the team | A workshop is delivered from slides, not from a page. These are condensed rewrites, not the document with its paragraphs shortened |

The four decks, and the sessions they belong to:

| Deck | Slides | Session |
| --- | --- | --- |
| [`03-team/coach_and_ai_rules.pptx`](03-team/coach_and_ai_rules.pptx) | 15 | W1 kick-off — the coach briefs the team on the AI and coach rules |
| [`04-training/frameworks.pptx`](04-training/frameworks.pptx) | 21 | Framework workshop — the five-minute selector and the toolbox |
| [`04-training/presentation_and_storyline_guide.pptx`](04-training/presentation_and_storyline_guide.pptx) | 36 | Delivery workshop — action titles, the 3-hour build, the boardroom pitch |
| [`06-templates/case_type_playbook.pptx`](06-templates/case_type_playbook.pptx) | 34 | Case-type workshop — recognising the six types in ten minutes |

The W1 kick-off deck is **not** here: it is hand-built in Beamer and lives at
[`../08-briefing-slides/abcc_overview.pdf`](../08-briefing-slides/abcc_overview.pdf).

## Rebuilding

Needs `pandoc` and a LaTeX installation with `lualatex` (MacTeX or TeX Live).

```bash
python3 tools/build_handouts.py            # all 37 PDFs
python3 tools/build_handouts.py 01-competition/handbook.md   # or just one
python3 tools/build_decks.py               # the four decks
python3 tools/check_decks.py               # flag slides whose content overflows
```

The deck house style lives in `tools/slides/abcc-reference.pptx`, generated by
`python3 tools/slides/make_reference.py` — rerun that only if the style itself
changes, then rebuild the decks.

**Keep them in step with the source.** These files are build output: after any
change to a markdown document — above all when the 2027 Competition Guide lands
and the propagation order in [`../DOCUMENTATION.md`](../DOCUMENTATION.md) §5 runs
— rebuild this folder as the last step. The four deck sources in
`tools/slides/` are condensed by hand and do **not** track their documents
automatically; re-read them against the source document when that document
changes.
